      新手部署到自己的 GitHub

      1. 在 GitHub 新建一个空仓库：不要勾选 README、.gitignore 或 License。
      2. 把两条推送目标改成你自己的仓库：源码 页的仓库（source 分支），以及 生成与推送 页的仓库（main 分支）。
      3. 回到后台点「推源码」提交并推送；需要发布页面时再点「生成并推送」。
      4. 如果仓库根目录有 vercel.json：在 Vercel 里 New Project → Import Git Repository，选中这个仓库，构建配置按 vercel.json 执行；之后每次推送到 main 都会自动部署。
