两种配置方式

任选一种，重启服务后生效。凭据只留在本机，不会进仓库。

  1. 双击 start-admin.cmd，按提示输入账号密码（可保存到 .admin-auth）
  2. 或手动在站点根目录建 .admin-auth，写两行 ADMIN_USER / ADMIN_PASSWORD
ADMIN_USER=admin ADMIN_PASSWORD=换成你的密码

开关已经写进配置文件，但生成的页面还是旧的。可以连续调整多项，最后点一次「重新生成」。

每项对应 _config.yml 或 _config.fomalhaut.yml 里的一个字段，点击开关会先弹出确认，确认后才写入。 只改白名单字段，配置文件里的注释和其它内容不会被重写，保存前会自动备份。

每次保存文章、站点配置或部署设置都会留一条记录，存放在 bak/admin/revisions/。 点开可以看这次改动的旧→新差异；回退前会把当前内容另存为新版本，所以回退本身也能再退回来。
